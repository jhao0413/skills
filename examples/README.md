# Examples

Small stills and GIFs from runs of these skills. Full MP4s are not included.

## motion-from-reference

`motion-from-reference/contact-sheet.png` — contact sheet of an original 1080×1080, 60 fps character animation built from a written motion spec (spring landing on the mascot, bezier and stagger on the type and UI, no bounce on interface chrome).

## bot-expression-animation

Two nine-state expression sets for different mascots, same pipeline (prefixed CSS-keyframe SVGs, 256px transparent GIFs, light/dark preview grid):

- `bot-expression-animation/pocket-bot-preview.png` and `pocket-bot-talking.gif` — a pebble-shaped bot with antenna and visor.
- `bot-expression-animation/ori-preview.png` and `ori-talking.gif` — a glossy black sphere whose expression lives in two highlight-like eyes.
